# 使用指南

[返回项目首页](../README.md) · [文档索引](README.md)

启动应用后打开 <http://127.0.0.1:8090>。首次使用请先在「模型库」下载模型，再回到「生图」页面生成。

## 文生图

选择已安装模型，输入提示词，选择画面比例后生成。切换模型时自动恢复对应的默认步数和引导设置。高级选项按模型能力显示：

- Qwen Image 2.1 Turbo 默认 8 步，引导系数固定为 1.0，使用专用采样曲线。
- Z-Image Turbo 不使用引导系数；FLUX.2 Klein 使用当前流程的默认引导设置。
- 随机种子留空时自动生成，也可以填写 `0` 到 `4294967295` 的整数，`0` 是有效种子。
- 步数接受 `1` 到 `100` 的整数；非法参数在任务入队前返回错误。

## 图生图

选择 PNG、JPG、JPEG 或 WebP 图片，或在生图页面直接按 ⌘V / Ctrl+V 粘贴截图。参考图会自动预览并展开高级选项，可替换或移除；点击生成时随请求上传，不会在粘贴后立即执行推理。

支持的浏览器也会提供“从剪贴板粘贴”按钮。如果浏览器拒绝剪贴板读取权限，可以直接使用键盘粘贴；普通提示词文本粘贴不受影响。

当前使用保留构图的图生图模式，参考图保留强度默认 `0.35`，范围为 `0` 到 `1`；值越高，保留原图越多、变化越少。参考图只作为临时文件使用，生成结束或任务失败后自动删除。

## Qwen 多参考图编辑

选择 **Qwen Image 2.1 Turbo**，展开高级选项，将“生成方式”切换为“多参考图编辑”。可以一次选择多张文件，也可以逐次选择或粘贴，最多 10 张。缩略图按添加顺序编号，点击“插入引用”会在提示词末尾添加 `<imageN>`。

例如上传人物照片为图一、衣服照片为图二，提示词可写：

```text
保留图一的人物身份和姿势，将衣服换成图二的款式。
```

“图一”“图2”会分别转换为 `<image1>`、`<image2>`。引用不存在的编号会在入队前报错。移除图片后会重新编号，请检查提示词；复用历史参数时，需按原顺序重新上传图片。

多参考图编辑使用模型的原生视觉编辑接口，不使用“参考图保留强度”；宽高需为 32 的倍数，至少 2 步，推荐保持 Turbo 默认 8 步。参考图数量增加会提高内存占用与耗时。现有完整 q4 仓库已包含视觉编码器与 processor；仅文本生成的精简导出权重不能替代完整编辑权重。其他模型目前仍使用单图保持构图模式。细节见 [Qwen Image 2.1 Turbo 接入](qwen-image-21-turbo.md)。

## 参考图提示词

生图页可以对参考图调用本地 Qwen3-VL 生成提示词，支持复制与一键填入。前置条件、输出结构与可选关注点见 [参考图提示词](image-description.md)。

## 模型库

模型页首先展示已安装模型。推荐模型区域提供 Hugging Face 和 ModelScope 两个 Tab，支持查看仓库、下载、查看进度和取消任务。推荐列表与渠道配置见 [模型与配置](configuration.md)。

### Krea 缓存兼容

Krea Turbo 的旧版 mflux 导出可能使用根目录分片，而不是单个 `turbo.safetensors`。程序会检查缓存快照中的分片索引与组件完整性，优先使用完整的本地快照；`main` 指向不完整快照时，也可以复用已有完整旧快照。无需重命名权重、修改 HF 缓存引用或重复下载整套模型。

## 生图反馈与队列

提交生成后，服务会立即返回任务 ID，并由单个 GPU worker 按提交顺序执行。生图页会显示排队位置、前方任务数和 ETA；生成中显示已耗时。

队列页面展示提交时间、状态、提示词、模型与参数、耗时和结果。模型名称与生图下拉框一致，仓库 ID 可通过模型名的提示查看。

成功任务使用“查看图片”文字按钮；失败任务使用同样样式的“查看日志”文字按钮。点击后通过 daisyUI 原生对话框显示完整日志，可滚动查看，使用关闭按钮、弹窗外区域或 Esc 关闭。

更新后产生的失败任务会保存任务级堆栈；历史记录如果没有保存堆栈，会显示当时记录的完整错误信息。日志只在打开弹窗时读取，列表不会反复传输完整堆栈。

模型在首次生成时加载并复用；默认连续 5 分钟没有新任务后自动卸载。服务重启不会恢复此前未完成的任务。
