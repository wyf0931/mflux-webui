# Qwen 多参考图编辑适配

## 范围

在现有单图保持构图模式之外，为 Qwen Image 2.1 Turbo 增加原生多参考图编辑。沿用已有 mflux 固定提交与完整 q4 权重，不改变其他模型的生成方式。Krea 同时修复优先选择完整缓存快照的问题。

## 交互与数据

- 显式切换“保持构图”与“多参考图编辑”，编辑模式接收 1–10 张有序图片。
- 缩略图展示图一至图十，支持逐张移除和插入 `<imageN>` 引用；中文“图一”“图2”等在推理前映射为对应标记，超出已上传数量时拒绝提交。
- HTTP 上传、持久化队列、后台推理、成功/失败清理贯通图片列表；保留旧单图请求与任务兼容性。
- 多图编辑使用 `QwenImage21Edit`，单图保持构图继续使用 `QwenImage21`；缓存区分模式，并在同一 Qwen 仓库切换模式时卸载另一实例，避免重复占用统一内存。
- 历史保留模式与参考图数量，复用参数时提示按原顺序重新上传图片。

## 验证

验证 Krea 旧完整快照与新不完整 main 的选择、分片缺失拒绝、Qwen 多图顺序与数量、引用校验、队列清理、模式缓存隔离及已有单图回归。使用本机已有权重执行 Krea 离线生图和 Qwen 双图编辑，不额外下载大型模型。
