# 简洁生成表单设计

## 目标

让 Krea 2 Turbo 的默认文生图表单只展示完成一次生成所必需的字段，避免空值导致的参数错误；高级参数和图生图能力按需展开。

## 默认模式

默认只展示提示词、宽度、高度、步数和生成按钮。步数保留是因为它对速度与质量的取舍直接可见，默认值为 8。

## 高级模式

点击“高级模式”后展开两部分：

- 引导系数：可不填；前端默认显示 3.5，后端空值回退到 3.5。
- 参考图：可选上传 PNG、JPG、JPEG 或 WebP；上传后自动显示参考图强度，默认 0.35。未上传图片时不发送该字段，也不向 mflux 传入 `--image`。

## 后端容错

空字符串、缺失值和 null 均视为未填写。后端只在存在参考图时解析并验证参考图强度；对空的引导系数采用默认值。这样 API 调用方不依赖前端也不会触发 `float('')` 错误。

## 验证

补充测试覆盖：普通模式提交空的高级字段、上传参考图但未传强度、以及高级模式的自定义强度。现有文生图和文+图生图命令构造测试继续通过。
